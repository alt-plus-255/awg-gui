# Telegram-бот

**Языки:** [Русский](telegram.md) | [English](../en/telegram.md) | [README](../../README.md)

Админский бот для удалённого управления панелью AWG-GUI из Telegram: конфиги, пиры, подключения резолвера, резолвер на серверных конфигах и уведомления online/offline пиров.

Доступ только у одного пользователя — числового **Admin Telegram ID**. Остальные при `/start` получают «Доступ запрещён»; прочие сообщения игнорируются.

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой числовой user id (например через [@userinfobot](https://t.me/userinfobot)).
3. В панели откройте **Настройки → Telegram**.
4. Укажите токен, Admin ID, язык бота (`en` / `ru`) и режим транспорта.
5. При необходимости включите уведомления пиров и (для long polling) пул прокси.
6. Сохраните настройки и нажмите **Проверить бота**.
7. В Telegram отправьте боту `/start` от аккаунта с Admin ID.

В Docker-контейнере `awggui-app` Go-процесс автоматически запускает Telegram poller. Планировщик каждую минуту проверяет online/offline пиров.

## Режимы транспорта

| Режим | Когда использовать | Как работает |
|-------|--------------------|--------------|
| **Long polling** (по умолчанию) | VPS без входящего HTTPS от Telegram, в т.ч. в РФ | Контейнер опрашивает `getUpdates`; можно задать пул SOCKS5/HTTP или подключения резолвера |
| **Webhook** | Панель доступна Telegram по HTTPS | Telegram шлёт updates на URL панели; пул прокси **не** используется |

Webhook URL (секрет генерируется автоматически при сохранении):

```text
{URL_панели}/api/telegram/webhook/{secret}
```

Запрос дополнительно проверяется заголовком `X-Telegram-Bot-Api-Secret-Token`. Неверный секрет → `404`. Секрет и токен бота в API панели маскируются и в браузер не отдаются.

После смены режима или токена сохраните настройки: бэкенд сам вызовет `setWebhook` / `deleteWebhook`.

## Что умеет бот

Навигация — inline-кнопки. Единственная slash-команда: **`/start`** (сбрасывает мастер и показывает главное меню).

### Главное меню

| Раздел | Возможности |
|--------|-------------|
| **Конфиги** | Список, создание (сервер / виртуальная сеть), вкл/выкл, редактирование имени/порта/DNS, удаление (нельзя удалить последний), пиры |
| **Пиры** | Создание, вкл/выкл, удаление, отправка VPN URI |
| **Подключения** | Создание из share-URL (`vless://`, `ss://`, `trojan://`, …), вкл/выкл, удаление |
| **Резолвер** | Только для конфигов типа «Сервер»: вкл/выкл, community-списки, выбор подключения |
| **Уведомления** | Переключатель оповещений online/offline пиров |
| **Обновить** | Синхронизация статистики пиров из Docker и обновление дашборда |

На главном экране — статус AWG и endpoint, счётчики пиров, CPU/RAM/диск, список онлайн-пиров.

## Уведомления пиров

Если уведомления включены (в настройках или в боте), раз в минуту сравнивается online-статус пиров с предыдущим снимком. При переходе online → offline или наоборот админу уходит сообщение.

Первый проход только фиксирует baseline — массовой рассылки при старте нет.

## Пул прокси (только long polling)

Нужен, если с сервера напрямую недоступен `api.telegram.org`.

Можно комбинировать:

1. **URL-прокси** — `socks5://`, `socks5h://`, `http://`, `https://` (перед добавлением в UI выполняется проверка).
2. **Подключения резолвера** — sing-box поднимает локальный mixed inbound (`:18088`) с авторизацией; бот ходит в Telegram через выбранные outbounds.

Стратегия выбора в настройках: предпочитать меньший пинг или первый доступный. В UI есть **Проверить прокси**.

## Настройки в панели

| Поле | Описание |
|------|----------|
| Токен бота | Из @BotFather; пустое/замаскированное значение при сохранении оставляет текущий токен |
| Admin Telegram ID | Числовой user id единственного оператора |
| Язык бота | Сообщения и кнопки: English / Русский |
| Режим транспорта | Long polling или Webhook |
| Уведомления пиров | Online/offline в чат админа |
| Пул прокси | Только в режиме polling |

## Встроенные воркеры

| Воркер | Назначение |
|--------|------------|
| Telegram poller | Long-polling (стартует вместе с Go API) |
| Peer notify | Одна проверка online/offline (каждую минуту) |

Если бот не настроен или выбран webhook, poller простаивает (idle).

## Безопасность

- Управление доступно только Admin Telegram ID.
- Webhook защищён секретом в пути и в заголовке Telegram.
- Токен, webhook secret и URL прокси в ответах API маскируются.
- Маршрут webhook публичный (без сессии панели), но с throttle и проверкой секрета.
